## Dynamic Island for Windows — Бета 0.1 🏝️

Первый публичный релиз динамического острова в стиле macOS / iOS для Windows 10 и 11.

### ✨ Что внутри:
* **Медиаплеер:** автоматически подхватывает треки, обложки и прогресс из Spotify, Яндекс Музыки, VK и любых браузеров.
* **Адаптивный градиентный эквалайзер:** окрашивается под основные цвета обложки играющего трека.
* **Компактный режим (Small):** аккуратная пилюля с мини-обложкой и эквалайзером в свернутом виде.
* **Таймер Apple-style:** быстрый запуск по кнопке `⏱+1м` в развернутом плеере, пауза, сброс и обратный отсчет.
* **Поверх всех окон:** плавная векторная отрисовка без пикселей и белых рамок.

### ⚠️ Известные ограничения:
* **Бета-версия (0.1):** возможны мелкие баги.
* Анимация подключения Bluetooth-наушников / AirPods в этой сборке **пока не работает** — починим в следующем обновлении.

### 🚀 Запуск и управление:
1. Скачай **`island.exe`** ниже и запусти двойным кликом.
2. Наведи курсор на островок сверху экрана, чтобы раскрыть плеер или таймер.
3. **Чтобы закрыть программу:** нажми по островку **правой кнопкой мыши (ПКМ)**.

## Dynamic Island for Windows — Бета 0.2 🏝️

Большое обновление с передачей файлов на телефон по Wi-Fi и уведомлениями о заряде батареи!

### 🆕 Что нового в Бета 0.2:
* **AirDrop по локальному Wi-Fi (Dropzone + QR):** Перетащи любое фото или файл мышкой прямо на островок — внутри появится QR-код. Наведи камеру iPhone или Android, и файл моментально скачается по домашней сети без проводов и облаков.
* **Уведомление о 20% батареи:** При падении заряда ноутбука до 20% островок показывает красное предупреждение в стиле iOS. Клик по нему включает системный режим энергосбережения Windows и перекрашивает индикатор в жёлтый цвет *(тест анимации — клик колёсиком мыши по островку)*.

### ✨ Основной функционал:
* **Медиаплеер:** Перехват треков, обложек и прогресса из Spotify, Яндекс Музыки, VK и браузеров.
* **Адаптивный градиентный эквалайзер:** Автоматически окрашивается под основные цвета обложки играющего трека.
* **Таймер Apple-style:** Быстрый запуск по кнопке `⏱+1м` в развернутом плеере, пауза и сброс.

### ⚠️ Примечание по безопасности:
Так как `.exe` упакован через PyInstaller без платной цифровой подписи и поднимает локальный HTTP-сервер для передачи файлов по Wi-Fi, антивирус или Защитник Windows может выдавать ложное срабатывание. Весь исходный код полностью открыт в `island.py`.
