# Aleksey-404
## Dynamic Island for Windows — Бета 0.1 🏝️

Первый публичный релиз динамического острова в стиле macOS / iOS для Windows 10 и 11.

### ✨ Что внутри:
* **Медиаплеер:** автоматически подхватывает треки, обложки и прогресс из Spotify, Яндекс Музыки, VK и любых браузеров.
* **Адаптивный градиентный эквалайзер:** окрашивается под основные цвета обложки играющего трека.
* **Компактный режим (Small):** аккуратная пилюля с мини-обложкой и эквалайзером в свернутом виде.
* **Таймер Apple-style:** быстрый запуск по кнопке `⏱+1м` в развернутом плеере, пауза, сброс и обратный отсчет.
* **Поверх всех окон:** плавная векторная отрисовка без пикселей и белых рамок.

### ⚠️ Известные ограничения:
* **Бета-версия (0.1):** возможны мелкие баги.
* Анимация подключения Bluetooth-наушников / AirPods в этой сборке **пока не работает** — починим в следующем обновлении.

### 🚀 Запуск и управление:
1. Скачай **`island.exe`** ниже и запусти двойным кликом.
2. Наведи курсор на островок сверху экрана, чтобы раскрыть плеер или таймер.
3. **Чтобы закрыть программу:** нажми по островку **правой кнопкой мыши (ПКМ)**.
